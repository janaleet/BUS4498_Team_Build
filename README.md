# About the Agentic System

**BUS 4498 Team Build**

> **Problem to be solved**: Our system aims to decrease the time it takes an employee to write proposals for clients looking to book their event space. Currently, employees need to gather event information (guest count, type of event, time and date, etc.) to determine how many chairs and tables are need, AV equipment, which event space to use, and then write up a personal proposal or use a template, depending on how much information the client sent in. This currently takes employees 1 hour to complete and our target time is 30 minutes.
