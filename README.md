# About the Agentic System

**BUS 4498 Team Build**

> **Problem to be solved**: Our system aims to decrease the time it takes an employee to manually schedule in an event for customers intending to use the company's event space. Currently, the employee will have to cross reference the current calendar and ensure no previously scheduled events conflict with the clients request, check all guest information is input correctly, and transfer all event details into the calendar. This process takes the employees 5 minutes to complete.
