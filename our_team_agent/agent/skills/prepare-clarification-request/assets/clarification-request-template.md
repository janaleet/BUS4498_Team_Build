# Clarification request layout

The agent's code builds the final message from this layout. The Skill writes only the parts marked **(wording)**; code fills in the inquiry ID, the numbering, the reply-by date and the reply line. `[CLIENT NAME]` and `[EMPLOYEE NAME]` stay as written: the employee fills them in when sending from their own email.

---

**Subject:** <INQUIRY ID> – A few details needed for your event proposal

Hello [CLIENT NAME],

<Opening (wording): thank the client and name the event in their own words, e.g. "your sister's 40th birthday". End with "To prepare your proposal, we need a few more details:" or "one more detail:".>

1. **<Detail label>** — <Question (wording): what the client already said, if anything, then exactly what is needed and what a usable answer looks like.>
2. **<Detail label>** — …

<Closing note (wording), only if the client asked about price or availability: one sentence saying the proposal will include the room, setup and options once these details are in.>

Please reply to this message by **<Weekday, Month D, YYYY>**, keeping **<INQUIRY ID>** in the subject line, so we can match your answers to your request.

Thank you,
[EMPLOYEE NAME]
Reference: <INQUIRY ID>
